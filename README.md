# mammoth-game-mode

An agentic AI web app for Utah Mammoth fans during the game. Use natural language to ask questions or request structured output about game schedules, team rosters and standings, and predicted game outcomes.

## Setup

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) recommended for dependency management

```bash
uv sync
uv run <your-entrypoint>
```
